# NodeView · Cocos Asset Inspector

Cocos Studio UI(ExportJson), Armature(AR), Spine 리소스를 불러와 노드 구조·애니메이션·사용 리소스를 확인하는 도구입니다.
PlayLinks · Raon Studio

## 실행

| 방법 | 명령 | 비고 |
|---|---|---|
| 앱(Electron) | `electron` 폴더에서 `npm install` 후 `npm start` | 파일 열기, 폴더 드롭, 최근 파일 등 모든 기능 |
| 웹 모드 | 루트에서 `npm install` 후 `node app.js` → `http://localhost:8899` | 파일 열기·최근 파일은 앱에서만 |

## 화면 구성

왼쪽 **Assets / Hierarchy**, 가운데 **Game View**와 하단 탭(**Animation · Sequencer / Console / Dependencies**), 오른쪽 **Inspector**.
패널은 끌어서 옮기거나 다른 탭으로 합칠 수 있고, **창** 메뉴에서 열고 닫습니다. 배치를 처음으로 되돌리려면 상단의 **레이아웃 초기화**를 누릅니다.

## 기능

### 파일 불러오기
- ExportJson(UI·AR), Spine `.json`, png 파일이나 리소스 폴더를 **Assets** 패널로 끌어다 놓습니다. 앱에서는 **파일 › 열기(Ctrl+O)**, **리소스 폴더 열기**도 됩니다.
- 함께 쓰는 리소스(plist·png·fnt·atlas)는 파일 주변 폴더(`image` 폴더 등)에서 자동으로 찾아 불러옵니다. 못 찾은 파일은 **Dependencies**에 찾아본 경로와 함께 표시됩니다.
- 상단 **최근 파일**에서 최근에 연 파일을 다시 열 수 있습니다.

### 템플릿 (앱에서만)
- Game View에 배치한 인스턴스 구성(사용 파일, 위치·스케일·회전·보이기·순서, 선택한 애니메이션), 해상도, 배경색, 시퀀스를 `.nvtemplate` 파일로 저장합니다. 로비·슬롯 화면을 실제 게임처럼 한 번 배치해 두고 세트장처럼 다시 불러 쓰는 용도입니다.
- Hierarchy에서 다른 인스턴스나 UI 노드 아래로 옮긴 인스턴스도 그 자리(부모 노드 이름 경로)에 다시 배치합니다. 애니메이션 목록에서 미리보기로 고르거나 Inspector에서 재생한 애니메이션은 불러올 때 다시 재생합니다.
- 인스턴스 안의 하위 노드(UI 위젯 등)를 눈 아이콘이나 Inspector로 보이기/숨기기 한 것도 저장합니다. 바꾼 노드만 저장하며, 원본 노드 이름이 바뀌어 찾지 못하면 Console에 표시됩니다.
- **파일 › 템플릿 저장(Ctrl+S)**, **다른 이름으로 저장(Ctrl+Shift+S)**, **템플릿 열기**를 씁니다. 열면 지금 화면을 비우고 템플릿대로 다시 배치합니다.
- 파일 경로는 템플릿 파일 기준 상대 경로로 저장되므로, 템플릿을 리소스와 같은 폴더 구조 안에 두면 다른 PC에서도 열립니다. 못 찾은 파일은 Console에 표시됩니다.
- **기본 템플릿**: `electron/templates/<폴더>/<이름>.nvtemplate`(리소스와 함께 저장한 폴더)을 넣으면 앱에 내장되어 **파일** 메뉴의 기본 템플릿 목록에 나옵니다. 빌드하면 `resources/templates`에 들어갑니다. 기본 템플릿을 연 뒤 `Ctrl+S`를 누르면 원본을 덮어쓰지 않고 저장 위치를 새로 묻습니다.
- **템플릿을 리소스와 함께 저장**은 `이름/이름.nvtemplate`과 사용 파일(`res/`에 ExportJson·Spine json, `res/image/`에 plist·png·fnt·atlas)을 한 폴더로 만듭니다. 이 폴더만 전달하면 리소스가 없는 PC에서도 열 수 있습니다. 이렇게 연 템플릿은 `Ctrl+S`로 저장할 때도 리소스를 다시 복사합니다.

### Assets
- 에셋별로 사용하는 리소스 목록, 크기, 누락 여부를 보여줍니다. 검색과 종류 필터(UI·Spine·Armature·Image·누락)를 쓸 수 있습니다.
- 리소스를 더블클릭하면 **Resource View** 탭으로 열고, 에셋을 Game View로 끌어다 놓으면 인스턴스를 만듭니다.

### Hierarchy
- 인스턴스와 노드 트리를 보여줍니다. 이름 검색을 지원하고, `t:Text`처럼 쓰면 종류로 필터합니다.
- 눈 아이콘으로 보이기/숨기기, ✕로 삭제합니다.
- 순서 바꾸기는 끌어다 놓거나, 노드를 선택하고 하단 **순서** 바의 맨 위·위로·아래로·맨 아래 버튼, 우클릭 메뉴, `Ctrl+↑/↓`를 씁니다.
- **uiWidgets 복사**(`Ctrl+Shift+C`)는 UI 노드 구조를 `this._uiWidgets = {...}` 코드로 복사합니다. ▾에서 범위와 옵션을 고르고 미리보기를 볼 수 있습니다.
- 우클릭 메뉴에서 이 노드 아래만 uiWidgets 복사, 노드 이름 복사, 경로 복사를 할 수 있습니다.

### Game View
- **▶ 플레이(Ctrl+P)**: 실제 게임 화면 크기만 보여줍니다. 해상도에 맞춰 게임과 같은 규칙으로 정한 디자인 영역(예: 1136×610 → 1248×670)을 패널에 꽉 차게 보여주고, 영역 밖으로 나간 배경·연출은 검게 가립니다. 선택·이동·확대 등 편집은 막히고, 시퀀스가 있으면 처음부터 재생합니다. **■ 편집으로** 또는 `Esc`로 돌아오면 이전 보기 배율과 위치로 돌아갑니다.
- 도구는 선택(Q), 이동(W), 회전(E), 스케일(R)입니다. 회전할 때 Shift를 누르면 15도 단위로 돕니다.
- **Alt+클릭**으로 클릭한 위치의 가장 안쪽 노드를 선택합니다.
- 휠로 확대·축소하고, 가운데 버튼 드래그나 Space+드래그로 화면을 이동합니다. `F`는 맞춤입니다.
- 경계 상자, 앵커 표시, 그리드, 디자인 해상도 프레임, 통계(FPS·마우스 좌표)를 켜고 끌 수 있습니다.
- 해상도는 자동(패널 크기)이나 1280×720 같은 프리셋 또는 직접 입력으로 정하고, 배경색도 바꿀 수 있습니다.

### Inspector
- 노드 종류별 속성(Transform, Rendering, Widget, Text, Button, 텍스처, Layout, Spine, Armature 등)을 보여주고 수정합니다. 라벨을 좌우로 끌어도 숫자가 바뀝니다.
- **값 복사**는 현재 속성을 텍스트로 복사하고, **원래대로**는 처음 선택했을 때 값으로 되돌립니다.
- 텍스처 카드에서 사용 이미지를 미리 보고 Resource View로 열 수 있습니다.
- **키프레임 이벤트** 섹션에서 AR·Spine 애니메이션의 이벤트 목록을 보고, 누르면 그 위치로 이동합니다.

### Animation · Sequencer
- 왼쪽 목록에서 애니메이션을 누르면 미리보기하고, 끌어다 놓으면 트랙에 추가합니다. 이벤트가 있는 애니메이션에는 `◆ 개수`가 붙습니다.
- **시퀀스** 보기에서는 여러 인스턴스의 애니메이션을 타임라인에 배치해 재생합니다. 반복 재생을 켤 수 있고, 클립 위 ◆는 키프레임 이벤트입니다.
- **키프레임** 보기에서는 UI 노드·AR 본·Spine 타임라인별 키를 보여줍니다. ◆에 마우스를 올리면 값이 보이고, 누르면 그 프레임으로 이동합니다.

### Dependencies
- 선택한 에셋의 리소스별 로드 상태, 크기, 텍스처 메모리를 보여줍니다.
- 누락 파일은 찾아본 경로와 함께 표시하고, 직접 파일을 지정할 수 있습니다.
- 리소스를 고르면 **사용 노드**(쓰는 프레임 포함)가 나오고, 누르면 그 노드를 선택합니다. **Hierarchy에 표시**를 누르면 트리에서 강조합니다.
- 탐색기에서 열기, 목록 복사, Resource View로 열기를 할 수 있습니다.

### Resource View
png, plist(프레임 목록과 영역), Spine atlas, fnt를 탭으로 열어 확인합니다.

### Console · 상태바
- 로드 오류와 경고, 재생 중 발생한 키프레임 이벤트를 기록합니다.
- 하단 상태바에는 에셋·노드 수, 텍스처 메모리, 누락 리소스, 경고·오류 수가 나옵니다.

## 빌드 (exe 만들기)

`electron` 폴더에서 실행합니다.

```bash
npm install
npm run deploy:win
```

- 결과물은 `electron/dist/`에 생깁니다.
  - `NodeView Setup <버전>.exe`: 설치 파일(설치 경로 선택 가능)
  - `NodeView-<버전>-ia32-win.zip`: 압축만 풀어 쓰는 버전
  - `win-ia32-unpacked/NodeView.exe`: 바로 실행해 볼 수 있는 파일
- 기본 빌드는 32비트(ia32)입니다. 64비트로 만들려면 `npx electron-builder --windows nsis:x64`를 실행합니다.
- macOS용은 Mac에서 `npm run deploy:mac`로 만듭니다.
- 처음 빌드할 때는 Electron과 설치 파일 제작 도구(NSIS)를 내려받느라 몇 분 걸립니다.
- 버전은 `electron/package.json`의 `version`에서 바꿉니다.
- 코드 서명을 하지 않아서 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다. **추가 정보 › 실행**으로 넘어가면 됩니다.
- 화면에 쓰는 라이브러리와 글꼴(`client/lib`, `client/fonts`)은 모두 앱 안에 들어 있어서, 인터넷이 없어도 동작합니다.
- 빌드에 포함할 파일은 `electron/package.json`의 `build.files`에서 정합니다. 새 폴더를 추가하면 여기에도 넣어야 합니다.

## 참고

- 설정(패널 배치, 최근 파일, 해상도, 복사 옵션 등)은 `%APPDATA%\NodeView`에 저장됩니다. 예전 `NodeView(flysher)` 폴더가 있으면 처음 실행할 때 한 번 복사해 옵니다.
- UI 키프레임 툴팁의 "보이기" 값은 ExportJson에 저장된 값을 그대로 보여주므로, 실제 화면과 다를 수 있습니다.
